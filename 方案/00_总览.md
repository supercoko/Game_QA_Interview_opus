# 00 总览：游戏测试 / 测试开发能力提升方案

## 这套方案在解决什么问题

你的情况：三年在研项目经验（系统测试 + 质量工具），没有上线项目，缺少「真实 bug」和「工具的真实数据反馈」。面试时一被深挖就没有素材。

这套方案的思路：**用四款上线游戏的公开修复记录当作「别人的线上事故库」**，从里面归纳线上缺陷的规律，再把规律转化成三样东西：

1. **测试设计方法**：每个方法都有真实案例支撑；
2. **自动化和工具方案**：每个方案都对应数据里的一类问题；
3. **一个你可以讲、可以演示、可以深挖的作品**：`bug_insight` 分析工具。

## 快速开始

```bash
cd tool
python -m bug_insight analyze                         # 本机 python 不可用时：uv run --python 3.13 python -m bug_insight analyze
python -m bug_insight search 热切换                    # 查案例
python -m bug_insight checklist --module "战斗/角色/技能"
python -m unittest discover -s tests -t .
```

## 三条底线

1. **只讲真实经历**。标了 [填写] 的地方用真实经历填，没有就删掉。
2. **推测要说是推测**。公告看不到内部原因，「为什么漏测」都是推测。
3. **数字要能复现**。文档里的每个数字都能用工具重新算出来；你自己改过规则之后，以你重新跑出的结果为准。
